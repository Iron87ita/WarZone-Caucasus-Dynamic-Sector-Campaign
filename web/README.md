# WarZone Caucasus Web Command Center

MVP live dashboard for the WarZone Caucasus Dynamic Sector Campaign.

## What it does

- Shows server status, player count and mission time
- Shows the active sector and all 14 campaign sectors
- Shows NATO and RED progression paths
- Shows coalition credits
- Shows active operations and a live event feed
- Receives updates in real time through Server-Sent Events (SSE)
- Keeps enemy tactical positions out of the public feed by design

## Architecture

```text
DCS / WarZone mission
        |
        | writes strategic snapshot
        v
Saved Games/DCS.../WarZoneWeb/WarZoneWebState.json
        |
        v
web/server.js
        |
        +--> GET /api/state
        +--> GET /api/health
        +--> GET /events (SSE)
        |
        v
Browser dashboard
```

## Run locally

Requires Node.js 20 or newer.

```powershell
cd web
npm start
```

Open:

```text
http://localhost:8787
```

By default the server reads `web/data/state.json`, which is included as demo data.

## Connect it to the DCS server

Set `WARZONE_STATE_FILE` to the JSON file generated by the Lua bridge.

Example on Windows PowerShell:

```powershell
$env:WARZONE_STATE_FILE="$env:USERPROFILE\Saved Games\DCS.openbeta_server\WarZoneWeb\WarZoneWebState.json"
$env:PORT="8787"
node server.js
```

Adjust the Saved Games folder name to match the actual Dedicated Server installation.

## Lua bridge

`bridge/WarZoneWebBridge.lua` contains the first bridge contract.

The current `collect()` implementation is deliberately conservative and must be adapted to the real WarZone objects contained in the mission. The next integration step is to map:

- ZoneCommander sector ownership/state
- Current NATO / RED progression
- Coalition credits / shop economy
- Dynamic mission tasking
- Campaign event feed
- Multiplayer player count

Do not export exact enemy aircraft, SAM or ground-unit positions to the public dashboard unless a delayed/admin-only view is implemented.
